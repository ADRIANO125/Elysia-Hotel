## 🌟 About

**Elysia Hotel** is a luxurious and modern hotel booking website designed to deliver a premium online experience. Developed with **React.js**, styled using **Bootstrap 5** and **Bootstrap Icons**, and powered by **React Router DOM** for smooth navigation. Deployed seamlessly on **Vercel** for top-notch performance and reliability.

---

## ✨ Features

- ✅ Elegant and responsive hotel design
- ✅ Fast and smooth page navigation
- ✅ Clean reusable React components
- ✅ Bootstrap & Bootstrap Icons integration
- ✅ SEO-friendly and performance-optimized
- ✅ Deployed on Vercel for instant global access

## ⚙️ Installation & Setup

### Clone the repository:

```bash
git clone https://github.com/ADRIANO125/Elysia-Hotel.git
```

### Navigate to the project folder:

```bash
cd Elysia-Hotel
```

### Install dependencies:

```bash
npm install
```

### Run the project locally:

```bash
npm start
```

The app will open automatically on `http://localhost:3000`

## 🚀 Deployment on Vercel

1. Go to [Vercel](https://vercel.com)
2. Click **New Project**
3. Import your GitHub repository
4. Build Command → `npm run build`
5. Output Directory → `build`
6. Click **Deploy**

⚡ Within seconds, your Elysia Hotel website will be live!
